# JAS Photography Portfolio

Official redesigned website for **John Angelson Arellano (JAS)** — Art Director & Photographer based in Quezon City, Metro Manila.

## 🚀 One-Click Deploy to Vercel

### Option 1: Via Vercel Web Dashboard (Recommended)
1. Push this repository to **GitHub** (or drag & drop via GitHub Desktop).
2. Go to [vercel.com](https://vercel.com) and log in.
3. Click **"Add New..." → "Project"**.
4. Import your `JAS-PHOTOGRAPHY` GitHub repository.
5. Framework Preset: **Other** (Static HTML).
6. Click **Deploy**. Vercel will give you a live production URL (e.g. `https://jas-photography.vercel.app`) in seconds!

### Option 2: Via Vercel CLI in Terminal
1. Open terminal inside this folder in VS Code (`Ctrl + ~`).
2. Run:
   ```bash
   npx vercel
   ```
3. Follow the simple terminal prompts to link and deploy.
