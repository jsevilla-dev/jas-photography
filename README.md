# JAS PHOTOGRAPHY — Official Portfolio

> *A modern, editorial redesign of the original photography portfolio for **John Angelson Arellano (JAS)** — Art Director & Lead Photographer based in Quezon City, Metro Manila.*  
> *Redesigned and developed by [jsevilla-dev](https://github.com/jsevilla-dev).*

---

## 🦇 Overview & Design Vision

This project is a complete architectural and aesthetic overhaul of the original Wix portfolio (`saj080903.wixsite.com/jasphotography`). Built tailored to JAS's creative identity, the redesign embraces a high-contrast **The Dark Knight / Gotham Noir Monochrome** visual language:

- **Cinematic Monochrome System**: Pure pitch blacks (`#000000`), deep steel carbon shades, and crisp stark white accents matching the iconic Dark Knight bat emblem.
- **100% Authentic Portfolio Work**: Real high-resolution assets directly from JAS's archive (Landscapes, Editorial Portraits, Commercial Flatlays, and Grand Debut Cotillions).
- **Personalized Identity**: Features his actual current Instagram avatar (`@arellano_jas`) and original bio copy, refined into an authoritative creative statement.
- **Zero-Bloat Performance**: Built with pure vanilla HTML5, modern CSS3, and lightweight JavaScript — 100% Lighthouse ready, mobile-optimized, and instantly deployable on Vercel.

---

## ✨ Key Features

- **Dynamic Discipline Filtering**: Seamless category switching between *All*, *Events & Debuts*, *Portraits*, *Commercial & Product*, and *Landscapes* without page reloads.
- **Interactive Lightbox Modal**: Fullscreen high-definition photo inspection with keyboard navigation (`Esc`, `←`, `→`).
- **Responsive Mobile-First UX**: Sleek slide-down navigation drawer and horizontal touch-swipe filter tabs tailored for smartphones and tablets.
- **Direct Inquiry & Booking Dispatch**: Interactive client briefing form with service selectors and event date pickers.
- **Atmospheric Micro-Interactions**: Custom hardware-accelerated monochrome cursor, subtle film-grain texture, and smooth scroll-reveal triggers.

## 🚀 Deployment (Vercel)

The repository is pre-configured with a custom `vercel.json` for one-click deployment:

1. Import the repository into [Vercel](https://vercel.com/new).
2. Framework Preset: **Other** (Static HTML).
3. Click **Deploy**. Vercel automatically sets up global edge caching and instant clean URLs.
